# Harald Co-Pilot MVP

Ferramenta técnica de precisão para confeiteiros que trabalham com chocolates Harald.

## Funcionalidades

### 📊 Calculadora Unificada
- Cálculo preciso de custos por ingrediente
- Cálculo de rendimento baseado em fluidez do produto
- Simulador de troca entre chocolate nobre e cobertura fracionada
- Comparação de lucratividade em tempo real
- Sugestão de preço de venda baseado em markup
- Dados salvos automaticamente no navegador

### 🌡️ Assistente de Temperagem
- Guia passo a passo com temperaturas específicas para cada produto
- Timer integrado para controle de tempo
- Instruções personalizadas por método de resfriamento
- Detecção automática de coberturas fracionadas (que dispensam temperagem)
- Teste de secagem para validar a temperagem

### 📚 Catálogo Técnico
- Especificações completas de todas as linhas Harald
- Curvas de temperatura detalhadas
- Fatores de rendimento e fluidez
- Notas comerciais e instruções especiais

## Linhas de Produtos

- **Unique** - Chocolate Nobre Premium
- **Melken** - Chocolate Nobre
- **Top** - Cobertura Fracionada (dispensa temperagem)
- **Inovare** - Cobertura Fracionada
- **Confeiteiro** - Chocolate Nobre

## Tecnologias

- React 18
- TypeScript
- React Router 7
- Tailwind CSS v4
- Radix UI
- Lucide Icons

## Dados Persistentes

Os preços e configurações inseridos na calculadora são salvos automaticamente no localStorage do navegador, eliminando a necessidade de redigitar os valores a cada uso.
